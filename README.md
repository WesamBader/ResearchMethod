## MoleculeExplorer
### What My Code Does
This program takes a SMILES string and uses RDKit to calculate molecular properties such as exact molecular weight, hydrogen bond donors, TPSA, hydrogen bond acceptors, and rotatable bonds.
### What I Learned
I learned how to use RDKit to turn a SMILES string into a molecule object and calculate different molecular properties. I also learned how these properties can be used to describe and compare molecules.

# Chapter 7: Making Data Whole
## What I Did
I analyzed an alkane dataset and found missing chemical data. I tested list-wise deletion, mean imputation, Log-Linear Regression, KNN, Random Forest, and an Ensemble model. I compared the models using Mean Absolute Error (MAE) and created correlation and bias graphs.
I also used the Titanic dataset to study missing age data. I used mean imputation, KNN, and Random Forest to estimate missing ages and compared the models using MAE.
## What I Learned
I learned that deleting missing data can cause information loss and bias. I also learned that machine learning can estimate missing values using patterns in other data. MAE, correlations, and graphs helped me compare the different methods.
